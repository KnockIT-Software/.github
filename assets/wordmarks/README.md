# KnockIT Display — wordmark variants

These are exports from the same **KnockIT Display v0.16-A** wordmark geometry.

- [Original (transparent)](KnockIT_Display_original_transparente.svg) — black `Knock`, red `IT!`, transparent background; **displayed on the GitHub organization home**.
- [Black on white](KnockIT_Display_preto_e_branco.svg) — strict monochrome (black letters on white background).
- [Black (transparent)](KnockIT_Display_preto_transparente.svg) — same monochrome letters, alpha background.
- [Exact chromatic negative](KnockIT_Display_negativo_cromatico_RGB.svg) — white `Knock`, cyan `IT!`, black background by RGB inversion `255 − channel` of the original composited on pure white.

The paths, order, proportions and spacing of all letters remain unchanged across the variants. Variants are not declared separately homologated by their publication. No font binaries are modified.
